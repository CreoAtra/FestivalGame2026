# フルーツキャッチゲーム

上から降ってくるフルーツをキャラクターでキャッチし、制限時間内にスコアを稼ぐスマホ向けブラウザゲームです。

詳しい仕様は `要件定義書.md` を見てください。

## 動かし方

`index.html` をブラウザで開くだけで動きます。ビルドは不要です。

スマホでの見え方を確認したいときは、PCのChromeで開いて開発者ツール(F12)の端末ツールバーを使うと便利です。

## ファイルの役割

| ファイル | 担当 |
|---|---|
| `index.html` | 骨格。ファイルを追加したら `<script>` タグも足してください |
| `style.css` | UI |
| `main.js` | ゲームロジック(結合役)。共通変数もここにあります |
| `character.js` | キャラクター操作 |
| `fruit.js` | フルーツ生成 |
| `collision.js` | 当たり判定 |
| `ui.js` | UI |
| `assets.js` | アセット・演出 |
| `extra.js` | 発展機能 |
| `screens.js` | タイトル・結果・ランキング |
| `assets/` | 画像置き場 |

各ファイルの先頭に、何を書けばいいかのメモを入れてあります。

## 作業の進め方

1. `develop` ブランチに移動する
2. 自分用のブランチを切る(例: `feature/名前/character`)
3. 自分の担当ファイルを書く
4. Pull Request を出す

## 気をつけてほしいこと

- `main.js` の共通変数(`player` / `fruits` / `gameState`)は、担当以外は読むだけにしてください
- 関数の外に変数を置くときは、名前の先頭に担当を表す語を付けてください(詳しくは要件定義書 8.4)
- 他の担当から呼ばれる関数の名前を変えたいときは、先に Discord で相談してください
